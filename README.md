# Memory Game — HTML/CSS/JavaScript

A classic card-matching memory game built with vanilla JavaScript. Flip cards to find matching pairs — all pairs matched means you win.

## Features

- Card flip animation (CSS transforms)
- Match detection and pair locking
- Move counter and timer
- Shuffle on each new game
- Win detection with congratulations message

## Running

Open `index.html` in any browser — no build step or server required.

## Tech Stack

HTML5, CSS3 (3D flip transforms), Vanilla JavaScript
